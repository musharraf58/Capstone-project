# DevJob Tracker

🚀 A responsive React web application for browsing remote jobs and tracking job applications.

## Features

- 🔍 Browse Remote Jobs - Fetch real remote jobs from Remotive API
- 💾 Save Jobs - Track jobs you're interested in  
- ✏️ Manage Applications - Update application status
- 🗑️ Full CRUD Operations
- 📱 Responsive Design with Tailwind CSS
- 🎨 Modern UI with loading states and notifications

## Tech Stack

- React 18 + Vite
- React Router v6
- Context API
- Tailwind CSS
- Axios
- Lucide React
- JSON Server

## Installation

```bash
git clone https://github.com/musharraf58/Capstone-project.git
cd Capstone-project
npm install
npm start
```
